    匯入

    可匯入織思的 JSON 備份，或 Markdown、縮排文字大綱（每行一個主題，用縮排或 # 標題表示層級）。

    或把內容貼在下方

    嵌入網頁（iframe）

    產生一份唯讀的檢視器：讀者可以縮放、平移、收合分支，點主題可看備註、連結與附件，但不能修改。內容是目前這份心智圖的快照，之後修改需要重新產生。

    方法一：直接貼上嵌入碼

    內容全部包在嵌入碼裡，不用另外上傳檔案。適合部落格、Google 協作平台、Moodle 等可以貼 HTML 的地方。

    方法二：上傳檔案後用網址嵌入

    先下載檢視器 HTML，放到你的網站、GitHub Pages 或其他可公開網址的空間，再填入網址產生嵌入碼。Notion 這類只接受網址的地方要用這個方法。

    快捷鍵與操作

    選取主題後直接打字，就會取代成新文字。Mac 用 ⌘，Windows 用 Ctrl。

    Tab
    新增子主題
    Enter
    新增同層主題
    F2／雙擊
    編輯文字（編輯中 Shift+Enter 換行）
    Delete
    刪除主題或選取的關聯線
    Space
    收合／展開分支
    ↑ ↓ ← →
    移動選取
    ⌘ Z／⌘ ⇧ Z
    復原／重做
    ⌘ C ⌘ X ⌘ V
    複製、剪下、貼上整個分支；貼上多行文字會變成子主題
    ⌘ B／⌘ I
    粗體／斜體
    ⌘ F
    搜尋主題、備註與附件名稱
    ⌘ + ⌘ − ⌘ 0
    放大、縮小、符合畫面
    Esc
    取消選取、離開聚焦模式
    右鍵選單
    在主題上按右鍵（觸控螢幕長按）可加入附件與執行常用動作；鍵盤可按 Shift+F10
    附件縮圖
    附件會以縮圖顯示在主題下方，點縮圖就地放大預覽；預覽中用 ← → 切換、Esc 關閉
    拖放與貼上
    也可以把檔案拖到主題上，或複製圖片後在選取的主題上按 ⌘ V
