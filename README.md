# 織思心智圖

一個在瀏覽器裡就能使用的心智圖工具，操作方式參考 XMind 與 GitMind，適合用來整理思考架構、規劃專案、做讀書筆記。整個程式只有一個 `index.html` 檔，不需要安裝、不需要帳號，也不需要伺服器。

> 線上使用：https://fredcit.github.io/zhisi-mindmap/

## 主要功能

| 類別 | 功能 |
| --- | --- |
| 編輯 | 快捷鍵新增主題、直接打字取代文字、拖曳搬移、收合展開、復原／重做、複製貼上整個分支 |
| 結構 | 心智圖、邏輯圖、組織圖、魚骨圖，一鍵切換 |

| 輸出 | PNG、SVG、PDF、Markdown、JSON 備份、唯讀分享連結，以及可嵌入網頁的檢視器 |

## 開始使用

1. 用瀏覽器打開網址（或直接雙擊本機的 `index.html`）。建議使用 Chrome、Edge 或 Safari 的最新版本。
2. 第一次開啟會看到一份範例心智圖，可以直接在上面練習。
3. 點左上角 ☰ 打開「我的心智圖」列表，按「新增」建立自己的心智圖。
4. 點上方的標題文字可以改名。

所有修改都會**自動儲存**，畫面左下角會顯示「已自動儲存」與時間。

## 基本操作

### 新增與編輯主題

- **新增子主題**：選取主題後按 `Tab`。
- **新增同層主題**：選取主題後按 `Enter`。
- **編輯文字**：雙擊主題，或按 `F2`。編輯時按 `Enter` 完成，`Shift + Enter` 換行，`Esc` 取消。
- **直接打字**：選取主題後直接開始打字（注音、拼音都可以），會取代原本的文字。
- **刪除**：按 `Delete` 或 `Backspace`，會連同底下的子主題一起刪除。不小心刪錯可以按 `⌘/Ctrl + Z` 復原。

### 移動與收合

- **拖曳搬移**：按住主題拖到另一個主題上。
  - 放在目標**中央**：成為它的子主題。
  - 放在目標**上緣或下緣**（組織圖、魚骨圖的第一層是左右兩側）：插到它的前面或後面。
- **收合／展開**：把滑鼠移到主題旁的小圓點上點一下，或選取後按 `Space`。收合後圓點會顯示隱藏了幾個主題。

### 畫布

- **平移**：在空白處按住拖曳，或用滑鼠滾輪、觸控板雙指滑動。
- **縮放**：按住 `⌘/Ctrl` 再滾動滾輪，或觸控板雙指縮放；右下角也有縮放按鈕。
- **符合畫面**：按右下角的 ⛶ 按鈕或 `⌘/Ctrl + 0`。

### 切換結構

工具列中間可以切換四種結構，內容不會改變，只改變排列方式：

| 結構 | 適合 |
| --- | --- |
| 心智圖 | 發想、腦力激盪，主題平均分布在左右兩側 |
| 邏輯圖 | 由左到右推演，適合分析與條列 |
| 組織圖 | 由上往下的階層，適合組織架構、專案分工 |
| 魚骨圖 | 找原因、做檢討，中心主題放在魚頭 |

## 快捷鍵一覽

Mac 使用 `⌘`，Windows 使用 `Ctrl`。

| 按鍵 | 動作 |
| --- | --- |
| `Tab` | 新增子主題 |
| `Enter` | 新增同層主題 |
| `F2`／雙擊 | 編輯文字 |
| `Delete`／`Backspace` | 刪除主題或選取的關聯線 |
| `Space` | 收合／展開分支 |
| `↑` `↓` `←` `→` | 移動選取 |
| `⌘ Z`／`⌘ ⇧ Z` | 復原／重做 |
| `⌘ C`／`⌘ X`／`⌘ V` | 複製、剪下、貼上整個分支 |
| `⌘ B`／`⌘ I` | 粗體／斜體 |
| `⌘ F` | 搜尋 |
| `⌘ +`／`⌘ −`／`⌘ 0` | 放大、縮小、符合畫面 |
| `Shift + F10` | 打開選取主題的右鍵選單 |
| `Esc` | 取消選取、離開聚焦模式、關閉預覽 |

工具列右側的 **?** 按鈕可以隨時查看這份清單。

## 右鍵選單

在不同位置按右鍵（觸控螢幕請**長按**）會出現不同的選單：

- **主題上**：加入附件、預覽附件、新增子主題／同層主題、編輯文字、外框、概要、拉關聯線、聚焦、收合、複製／剪下／貼上、屬性面板、刪除。
- **附件縮圖上**：預覽、下載、放大顯示在主題上（圖片）、再加入附件、移除這個附件。
- **關聯線上**：編輯說明文字、反轉方向、刪除。
- **空白畫布上**：符合畫面、全部展開、收合到第一層、加入附件到中心主題、貼上。

## 附件與預覽

### 加入附件

- 在主題上按右鍵，選「📎 加入附件…」，可以一次選多個檔案。
- 也可以直接把檔案從桌面或檔案總管**拖到主題上**。
- 複製一張圖片後，選取主題按 `⌘/Ctrl + V` 也會加入附件。

### 縮圖

附件會以縮圖排列在主題文字下方：

- **圖片**：顯示圖片本身。
- **PDF**：顯示第一頁。
- **其他檔案**：顯示有顏色的檔案類型標籤（DOCX、XLSX、PPTX…）與檔案大小。
- 超過 5 個附件時，最後一格會顯示「+N」，點它可以看其餘的附件。

### 原地預覽

點任一個縮圖，預覽視窗會從縮圖的位置放大展開：

| 檔案類型 | 預覽方式 |
| --- | --- |
| 圖片 | 完整顯示，點一下切換原始大小 |
| PDF | 逐頁顯示（最多 80 頁） |
| Word（.docx） | 排成文件頁面 |
| Excel（.xlsx、.xls、.csv） | 表格顯示，可切換工作表 |
| 文字檔（.txt、.md、.json 等） | 直接顯示內容 |
| 影片、音訊 | 直接播放 |
| PowerPoint、舊版 .doc、壓縮檔等 | 無法預覽，提供下載按鈕 |

預覽中用 `←` `→` 切換同一個主題的其他附件，`Esc` 或點外側關閉，右上角可以下載。

> PDF、Word、Excel 的預覽需要從網路載入顯示元件，第一次開啟會稍等一下；離線時這三種檔案只能下載。

### 讓圖片大大地顯示在主題上

如果希望某張圖片直接放大顯示在主題上（而不是縮圖），在縮圖上按右鍵選「放大顯示在主題上」。想改回來，到屬性面板的附件清單點「改回縮圖」。

## 屬性面板

點工具列右側的「屬性」打開。選取不同的東西，面板內容也會不同：

**選取主題時**

- **樣式**：粗體、斜體、分支顏色（選「預設」會跟隨配色主題）。
- **標記**：優先順序 1～5、狀態（✅ ⏳ ❓ ❗ ❌）、符號（⭐ 🚩 💡 📌 等）。優先順序和狀態各只能選一個，符號可以多選。
- **備註**：寫補充說明，主題上會出現 📝。
- **超連結**：輸入網址，主題上會出現 🔗，點它會在新分頁開啟。
- **附件**：查看、下載、移除附件。
- **外框與概要**、**聚焦**、**拉關聯線**。

**沒有選取任何東西時**

- **分支配色**：經典、海洋、森林、莓果、墨色五套配色。

**選取關聯線時**

- 編輯說明文字、反轉箭頭方向、刪除。

## 整理思考的工具

### 外框

把一個分支用虛線框起來，強調它們是一組。選取主題後按工具列的「外框」，可以在屬性面板替外框加上標題。

### 概要

在一個分支旁邊加上大括號與一句歸納的結論。選取主題後按工具列的「概要」，在屬性面板輸入概要文字。

### 關聯線

連接兩個不在同一條分支上的主題，表示「因果」「對照」「參考」等關係：

1. 選取起點主題，按工具列的「關聯線」（或右鍵選「拉關聯線」）。
2. 點要連到的主題。
3. 在屬性面板輸入說明文字（可留空）。

按 `Esc` 可以取消。

### 聚焦模式

只看某一個分支，把其他內容暫時隱藏，適合專心展開一塊想法。選取主題後按工具列的「聚焦」。左上角會出現路徑，點「全圖」或按 `Esc` 回到完整的心智圖。

## 大綱檢視與搜尋

### 大綱檢視

點工具列右側的「大綱」，心智圖會變成可編輯的條列清單，適合快速打字整理。這裡的修改會即時同步到圖形：

| 按鍵 | 動作 |
| --- | --- |
| `Enter` | 新增同層項目 |
| `Tab` | 降一層（變成上一項的子項目） |
| `Shift + Tab` | 升一層 |
| `↑` `↓` | 移動到上一項／下一項 |
| 空白行按 `Backspace` | 刪除這一項 |

點「圖形」回到心智圖。

### 搜尋

按 `⌘/Ctrl + F` 或工具列的放大鏡，可以搜尋**主題文字、備註、附件檔名**。符合的主題會被標亮，按 `Enter` 跳到下一筆、`Shift + Enter` 跳到上一筆。被收合的主題會自動展開。

## 管理多份心智圖

點左上角 ☰ 打開「我的心智圖」：

- **新增**：建立一份新的空白心智圖。
- **切換**：點列表中的名稱。
- **刪除**：滑鼠移到項目上，點右側的 ✕，再按「刪除」確認。刪除後無法復原，重要的心智圖請先匯出備份。

## 儲存、備份與搬移

- 心智圖會**自動儲存在目前使用的瀏覽器裡**，關掉網頁再打開都還在。
- **換電腦、換瀏覽器、清除瀏覽資料**後就看不到原本的資料，所以請定期備份：
  1. 點工具列「匯出」→「JSON 備份」，並勾選「JSON 備份包含附件檔案」。
  2. 到另一台電腦或瀏覽器，打開織思 → 工具列「匯入」→ 選擇剛才的 JSON 檔。
- 匯入的心智圖會成為一份新的心智圖，不會覆蓋現有的內容。附件也會一起還原。

## 匯出與匯入

### 匯出（工具列「匯出」）

| 格式 | 說明 |
| --- | --- |
| PNG 圖片 | 高解析度，可貼進簡報或文件 |
| SVG 向量圖 | 放大不失真，可再用設計軟體編輯 |
| PDF | 單頁，方便列印與分享 |
| Markdown 大綱 | 含備註、連結、概要與附件檔名，可貼到 Notion、Obsidian 等筆記軟體 |
| JSON 備份 | 完整結構，可選擇是否包含附件，用來備份與搬移 |

圖片、SVG、PDF 會依照畫面上目前的展開狀態、聚焦範圍與配色輸出。

### 匯入（工具列「匯入」）

可以匯入：

- 織思匯出的 **JSON 備份**。
- **Markdown** 或**縮排文字**大綱：每行一個主題，用 `#` 標題或縮排表示層級，`>` 開頭的行會變成上一個主題的備註。例如：

```markdown
# 年度計畫
- 學習
  - 讀完 12 本書
  - 考取證照
- 健康
  - 每週運動三次
```

小技巧：在畫布上選取主題後，直接貼上多行文字（例如從筆記複製的條列），也會自動變成子主題。

## 分享唯讀連結

想讓別人看你的心智圖，又不希望被修改時，點工具列的「分享」：

1. 視窗打開就會自動產生連結，按「複製連結」。
2. 把連結用 LINE、Email、Classroom 等方式傳給對方。
3. 對方用瀏覽器打開就能觀看，不需要登入或安裝。

**讀者可以做的事**

- **放大縮小**：右下角的 − ＋ 按鈕、雙指縮放、`⌘/Ctrl` ＋滾輪，或按鍵盤 `+` `−`；雙擊空白處也會放大，按 ⛶ 或 `0` 回到符合畫面。
- **移動**：拖曳畫布，或用滾輪、觸控板滑動。
- **收合分支**（可在分享時關閉這個選項）。
- **看詳細**：點主題會在左下角顯示備註、連結與附件檔名。

讀者**不能**新增、編輯、刪除或搬移任何內容，畫面上方會標示「唯讀」。

**要注意的地方**

- 連結裡存的是產生當下的**內容快照**。之後修改心智圖，要重新產生連結再傳一次。
- 附件檔案不會放進連結，讀者只會看到檔名。需要讓讀者看附件內容，請改用下方的「嵌入」產生檢視器檔案。
- 內容直接存在網址裡，不會上傳到任何伺服器；但拿到連結的人都看得到，請只分享給適合的對象。
- 連結長度超過約 8,000 字元時，視窗會提醒你。太長的連結在部分通訊軟體裡可能被截斷，這時建議改用嵌入的方法二。

## 嵌入到其他網頁（iframe）

點工具列的「嵌入」，可以把心智圖放進部落格、Google 協作平台、Moodle、Notion 等地方。嵌入的是**唯讀檢視器**：讀者可以縮放、平移、收合分支，點主題看備註，點附件縮圖預覽，但不能修改。

**選項**

- 高度：iframe 的高度（像素）。
- 外觀：跟隨讀者系統、固定淺色或固定深色。
- 讀者可收合分支：是否允許讀者收合展開。
- 內嵌附件與圖片：把附件一起包進去，讀者才能預覽與下載。

**方法一：直接貼上嵌入碼**

按「複製嵌入碼」，貼到網站可以輸入 HTML 的地方。內容全部包在嵌入碼裡，不需要另外上傳檔案。附件很多時嵌入碼會很長，有些網站會有長度限制，這時改用方法二。

**方法二：上傳檔案後用網址嵌入**

1. 按「下載檢視器 HTML」。
2. 把檔案放到可公開網址的地方，例如這個 GitHub 儲存庫的 `maps/` 資料夾。
3. 把網址填回對話框，按「複製網址嵌入碼」。

Notion 這類只接受網址的平台要用方法二。

> 嵌入的是當下的快照。之後修改心智圖，需要重新產生嵌入碼或重新上傳檢視器檔案。

## 資料與隱私

- 心智圖和附件**只存在你自己的瀏覽器裡**，不會上傳到任何伺服器，包括 GitHub。
- 其他人打開同一個網址，看到的是他自己瀏覽器裡的資料，看不到你的心智圖。
- 只有你主動「匯出」或「嵌入」時，內容才會離開瀏覽器。
- 字型會從 Google Fonts 載入；預覽 PDF、Word、Excel 與匯出 PDF 時，會從 cdnjs 等公開 CDN 載入顯示元件。這些請求不包含你的心智圖內容。

## 已知限制

- PowerPoint、舊版 `.doc`、壓縮檔等無法預覽，只能下載。簡報想預覽可以先另存成 PDF 再加入。
- PDF 預覽最多顯示前 80 頁。
- 瀏覽器的無痕模式關閉視窗後會清除資料，請不要在無痕模式中長期使用。
- 單一附件上限 200 MB。附件很多時，請留意瀏覽器的儲存空間，並定期匯出備份。
- 匯出 PNG／PDF 時，如果電腦沒有安裝 Noto Sans TC 字型，會改用系統的中文字型（例如蘋方、微軟正黑體），字寬可能有些微差異。

## 部署到 GitHub Pages

1. 在 GitHub 建立一個 **Public** 儲存庫，例如 `zhisi-mindmap`。
2. 上傳 `index.html` 與本檔案 `README.md` 到儲存庫根目錄。
3. 進入儲存庫的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 等 1～2 分鐘，網址會是 `https://你的帳號.github.io/zhisi-mindmap/`（本專案為 https://fredcit.github.io/zhisi-mindmap/）。

更新版本時，上傳新的 `index.html` 覆蓋舊檔即可，使用者的資料不受影響。

> 注意：不同網址的資料互不相通。從其他地方（例如本機檔案或其他網址）搬過來時，請先在原處匯出 JSON 備份，再到新網址匯入。
